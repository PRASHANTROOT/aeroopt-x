Troubleshooting

Common problems and what to check.

ERROR

Page does not load

  • Confirm Flask is running.
  • Check the terminal for Python errors.
  • Confirm template file locations.
CHECK

API request failed

  • Check the browser console.
  • Check Flask server logs.
  • Verify the API route exists.
TIP

Results look unexpected

  • Verify geometry inputs.
  • Check Mach number and altitude.
  • Compare multiple configurations.
