AEROOPT-X ENGINE

Documentation

AeroOpt-X is an engineering analysis environment for aerodynamic geometry generation, drag estimation, optimization, aerothermal calculations, trajectory simulation, and parametric analysis.

01

Aerodynamics

Generate and compare multiple nose cone geometries using backend-computed drag analysis.

02

Optimization

Use the SciPy SLSQP optimizer to determine an optimized parabolic geometry parameter.

03

Flight Analysis

Simulate two-degree-of-freedom flight trajectories and evaluate performance metrics.

01 / GETTING STARTED

Running an Analysis

The main AeroOpt-X Engine page provides the primary aerodynamic analysis workflow.

1

Configure Geometry

Enter the nose cone length and base radius. Values can be entered using sliders or exact numerical inputs.

2

Set Flight Conditions

Select the Mach number and target altitude for atmospheric and aerodynamic calculations.

3

Run Analysis

Click Analyze AeroOpt-X. The browser sends the configuration to the Python backend.

4

Review Results

Compare drag factors, geometry profiles, thermal results, and optimization output.

02 / AERODYNAMICS

Nose Cone Geometry Analysis

AeroOpt-X generates several nose cone profiles for aerodynamic comparison.

Sears-Haack

A low-wave-drag body distribution commonly used as a theoretical reference for supersonic aerodynamic optimization.

Von Kármán

A smooth aerodynamic nose profile that provides a practical geometry for high-speed vehicles.

Tangent Ogive

A common engineering geometry with a curved profile that is frequently used in vehicle nose design.

Optimized Parabolic

A parameterized parabolic geometry generated using the AeroOpt-X optimization workflow.

03 / OPTIMIZATION

SciPy SLSQP Optimization

AeroOpt-X uses the Sequential Least Squares Programming optimization method to determine the parabolic parameter that minimizes the configured aerodynamic objective.

Optimization Workflow
1. Create geometry
2. Configure drag solver
3. Initialize AeroOptimizer
4. Run SLSQP optimization
5. Obtain optimal K parameter
6. Generate optimized geometry
7. Compute optimized drag
Important: Optimization results depend on the geometry, atmospheric conditions, Mach number, and objective implementation in the Python backend.

05 / FLIGHT

2DOF Flight Trajectory

The trajectory engine simulates vehicle motion in two dimensions using the configured thrust, mass, drag, burn duration, and wind conditions.

Metric
Description
Apogee
Maximum altitude reached during simulation.
Downrange
Horizontal distance traveled.
Maximum Velocity
Highest velocity reached during flight.
Flight Time
Total simulated trajectory duration.
06 / PARAMETRIC ANALYSIS

Parametric Sweeps

Parametric sweeps evaluate drag behavior across a range of Mach numbers and fineness ratios.

Sweep Parameters
